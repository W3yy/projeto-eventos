# Natura — Eventos de Ciências da Natureza

Trabalho SENAI

Projeto com  Next.js e API REST em Node.js/Express para divulgar eventos de Ciências da Natureza. 

## Frontend

```bash
cd frontend
cp .env.example .env.local
npm install
npm run dev
```

## Backend

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

http://localhost:3000. O frontend inclui página inicial, agenda, detalhe de evento, página sobre e formulário de publicação.
